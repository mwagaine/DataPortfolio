# Data Engineering Projects

<ins>ETL pipeline</ins>
<br>
In this project, I extracted music sales data from the web and transformed it using Python, PySpark and Databricks, before loading it into a PostgreSQL database via AWS and exploring the data with SQL queries. 


<ins>CDC pipeline</ins>
<br>
With the same data from the ETL pipeline, I loaded the data from the PostgreSQL database to a new MySQL database via AWS, Python and PySpark, and replicated any data changes made at the source in the target.
